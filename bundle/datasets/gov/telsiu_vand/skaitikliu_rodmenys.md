### Portal Description (`@lt`)

Duomenų rinkinyje pateikiami UAB „Telšių vandenys“ renkami ir kaupiami įmonėms ir gyventojams įrengtų geriamojo vandens skaitiklių rodmenų duomenys. Rinkinį sudaro informacija apie abonentą, apytikslės skaitiklio koordinatės Lietuvos koordinačių sistemoje, tam tikro periodo skaitiklio rodmenys, mokėtojo tipas ir kita informacija. Duomenys renkami nuo 2005 metų. Duomenų teikėjas – UAB „Telšių vandenys". Su duomenimis susijusiais klausimais prašome kreiptis el. paštu atverimas@stat.gov.lt. Dėl techninių portalo veiklos sutrikimų prašome kreiptis el. paštu atviriduomenys@vssa.lt.[^dcat]

### Portal Description (`@en`)

The data set contains the reading data of drinking water meters installed for enterprises and residents collected and accumulated by Telšiai vandenys UAB. The set consists of information about the subscriber, approximate meter coordinates in the Lithuanian coordinate system, meter readings for a certain period, payer type and other information. Data have been collected since 2005. Data provider – UAB Telšiai vandenys. Contact the atverimas@stat.gov.lt for technical questions or possible errors.[^dcat]
